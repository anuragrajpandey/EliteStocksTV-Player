# EliteStocks TV

EliteStocks TV is a real-time stock market monitoring and streaming application for **Windows**. It delivers live market data, charts, and curated financial content in a single desktop dashboard.

> **Platform support:** Windows only (Windows 10 / Windows 11, 64-bit).
> EliteStocks TV is not available for macOS, Linux, or mobile platforms.

---

## Features

- 📈 Real-time stock quotes and market data
- 📊 Interactive charting and technical indicators
- 📺 Live financial news and market commentary streaming
- 🔔 Custom price alerts and watchlists
- 🗂️ Portfolio tracking and performance summaries
- 🖥️ Native Windows desktop experience

---

## System Requirements

| Requirement | Minimum |
|---|---|
| OS | Windows 10 (64-bit) or later |
| Processor | Dual-core 2.0 GHz+ |
| RAM | 4 GB (8 GB recommended) |
| Storage | 500 MB free disk space |
| Internet | Broadband connection required for live data |
| .NET Runtime | .NET 6.0 or later |

---

## Installation

1. Download the latest `EliteStocksTV-Setup.exe` from the [Releases](#) page.
2. Run the installer and follow the on-screen instructions.
3. Launch **EliteStocks TV** from the Start Menu or Desktop shortcut.
4. Sign in or create an account to begin streaming live market data.

> **Note:** Windows SmartScreen may show a warning for unsigned builds. Click **More info → Run anyway** to proceed, or verify the publisher signature before installing.

---

## Getting Started

1. Open EliteStocks TV.
2. Add tickers to your watchlist using the search bar.
3. Customize your dashboard layout (charts, news feed, alerts).
4. Enable notifications in **Settings → Alerts** to receive real-time price updates.

---

## Configuration

Application settings and cached data are stored at:

```
%APPDATA%\EliteStocksTV\
```

To reset the app to default settings, close the application and delete this folder.

---

## Troubleshooting

- **App won't launch:** Ensure the .NET 6.0 (or later) runtime is installed.
- **No live data:** Check your internet connection and firewall settings; EliteStocks TV requires outbound access on ports 443/80.
- **Installer blocked by Windows Defender:** Confirm the download source and allow the app through **Windows Security → App & browser control**.
