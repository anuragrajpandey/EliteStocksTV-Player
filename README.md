# EliteStocks TV

EliteStocks TV is an IPTV player application for **Windows**. It lets you stream live TV channels and on-demand content through M3U/Xtream Codes playlists in a clean desktop interface.

> **Platform support:** Windows only.
> EliteStocks TV is not available for macOS, Linux, or mobile platforms.

## Features

- 📺 Stream live TV channels via M3U playlists or Xtream Codes API
- 🗂️ Organized channel groups and categories (EPG support)
- ⏯️ Video-on-demand (VOD) and series/catch-up playback (if provided by your source)

## Installation

1. Download the latest installer from the [Releases page](https://github.com/anuragrajpandey/EliteStocksTV-Player/releases/tag/v2.4.0).
2. Run the installer and follow the on-screen instructions.
3. Launch **EliteStocks TV** from the Start Menu or Desktop shortcut.
4. Add your IPTV playlist/provider to start streaming.

> **Note:** Windows SmartScreen may show a warning for unsigned builds. Click **More info → Run anyway** to proceed, or verify the publisher signature before installing.

---

## Getting Started

1. Open EliteStocks TV.
2. Go to **Settings → Playlist** and add your source:
   - **M3U URL** — paste your M3U playlist link, or
   - **Xtream Codes** — enter server URL, username, and password
3. Wait for the channel list and EPG (if available) to load.
4. Browse categories or search for a channel and click to play.

> EliteStocks TV does not provide or host any channels, streams, or content. You must supply your own valid IPTV playlist or subscription from a legitimate provider.

## Configuration

Application settings, playlists, and cached data are stored at:

```
%APPDATA%\EliteStocksTV\
```

To reset the app to default settings or remove saved playlists, close the application and delete this folder.

---

## Troubleshooting

- **Channels won't load:** Verify your playlist URL/credentials are correct and still active with your provider.
- **Buffering or playback issues:** Check your internet speed; higher-quality streams require more bandwidth.
- **Installer blocked by Windows Defender:** Confirm the download source and allow the app through **Windows Security → App & browser control**.
